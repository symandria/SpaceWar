# SpaceWar

A turn-based space combat game with real-time battle animations, built with MonoGame.

## Project Overview
SpaceWar is a reimplementation of a classic space combat game, focusing on clean architecture, maintainability, and extensibility. The game features turn-based strategy with real-time battle animations, multiple races, and customizable ships.

## Project Structure

```
SpaceWar/
├── SpaceWar.Core/    # Main game project
├── SpaceWar.UI/      # UI components library
├── SpaceWar.Tests/   # Test project

```

## Development Setup
1. Install Visual Studio 2022 with .NET 6.0
2. Install MonoGame Extension for Visual Studio
3. Clone this repository
4. Open the solution in Visual Studio

## Game Features
- Turn-based space combat with real-time animations
- Multiple playable races with unique ships
- Customizable ships and loadouts
- Dynamic battle system
- Save/Load game functionality
- Particle effects and smooth animations
